# Homework Hero (Ödev Kahramanı) 🚀

Homework Hero, öğrencilerin ödev yapma alışkanlıklarını oyunlaştırarak eğlenceli hale getiren, modern ve etkileşimli bir görev yönetimi uygulamasıdır. Kullanıcılar görevlerini tamamladıkça kupalar kazanır, seviye atlar ve "seri" (streak) yaparlar.

## 🛠️ Teknoloji Yığını (Tech Stack)
- **Framework:** React + Vite
- **Stil & Tasarım:** Tailwind CSS
- **İkonlar:** Lucide-React
- **Animasyonlar:** Framer Motion
- **Yerelleştirme (i18n):** react-i18next (TR & EN destekli)
- **Veri Saklama:** Tarayıcı Local Storage (Özel `storage.js` ile yönetiliyor)
- **Mobil Uyumluluk:** Responsive Grid, Capacitor (Hazırlık Aşamasında)

## 📌 Proje Prensipleri (AI Ajanları İçin)
Yeni bir AI Ajanı projeyi devraldığında **MUTLAKA** `DEVELOPMENT_STANDARDS.md` dosyasını okumalıdır. Projenin yerelleştirme (i18n), saat dilimi (timezone), performans (`useMemo`) ve mobil uyumluluk kuralları kesinlikle esnetilemez.

## 🚀 Çalıştırma (Geliştirici Modu)
```bash
npm install
npm run dev
```

*Bu proje, Antigravity AI tarafından geliştirilmiş ve denetlenmiştir.*
